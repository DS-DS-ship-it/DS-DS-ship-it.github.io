Living Artwork fix

The Image Painter card now includes both the normal published launcher and a direct index.html fallback. That gives you two ways to open the same app path after push.

  1. Test locally with http://127.0.0.1:8080/living-artwork/.
  2. Also test http://127.0.0.1:8080/living-artwork/index.html.
  3. After push, test both live versions with a cache-buster if needed.
  4. If one path ever fails, the other button on the card gives you a backup launcher.
