📬 Why Your Full Personal Accounts Failed to Receive:

When an existing email account (Gmail, Outlook, Yahoo) runs out of storage, external mail servers reject every single message with error 552 Mailbox Quota Exceeded. Because ZeroMail stores emails on your computer's hard drive instead of a full cloud account, it never suffers from cloud quota limits.

Testing Without Personal Email:

Use "Send Test to My ZeroMail Address" to test the local inbox pipeline. This writes a local test message; it does not send an Internet email.

🌐 Outbound delivery

GitHub Pages is static hosting and cannot act as an SMTP server. Configure a serverless endpoint (for example, a Cloudflare Worker) to send through a provider. Never put provider API keys in this page. Without an endpoint, ZeroMail saves a local copy or opens your device's mail app.
