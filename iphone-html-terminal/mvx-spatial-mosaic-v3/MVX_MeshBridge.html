MeshBridge

Offline-first peer-to-peer mesh networking for low-latency communication, relay networking, store-and-forward transport, file transfer, Internet gateway sharing and future multi-radio expansion.

Native Mesh Engine

MeshBridge runs as a native networking engine and can expose the same MVX network to multiple computers, phones, tablets and future radio transports.

Intelligent Relays

Nodes do not have to communicate directly with every other node. A middle computer can relay packets, allowing multiple short links to form one larger effective mesh.

Offline First

MeshBridge is designed to continue operating when normal Internet connectivity is unavailable, using peer relays, routing and store-and-forward behavior.

Security

The native MVX networking layer is designed around authenticated node identities, encrypted peer sessions, key exchange and authenticated encrypted messages.

Multi-Transport

The routing layer is intended to operate above individual transports, allowing Wi-Fi, Ethernet, Bluetooth, LoRa and Meshtastic-compatible radios to participate in the same logical network.

Effective Range

Adding relay nodes increases effective network coverage without pretending that the radio itself has gained additional transmit power.
