MVX NETWORKING

MeshBridge

Offline-first peer-to-peer mesh networking for low-latency communication, relay networking, store-and-forward transport, file transfer and future multi-radio expansion.

Release 1.1.0
Download macOS ARM64 GitHub

Native Mesh Engine

The current release is a standalone native macOS ARM64 executable produced from the MeshBridge Python engine using Nuitka.

Low-Latency Design

TCP_NODELAY, tuned socket buffers, priority queues, duplicate suppression, bounded routing and asynchronous networking are used throughout the current engine.

Offline First

MeshBridge is designed to continue operating when normal Internet connectivity is unavailable, using peer relays, persistence and store-and-forward behavior.

Run MeshBridge

Download the macOS ARM64 package, extract it, and start a node:

./MVX-MeshBridge-macos-arm64 node

Security

The current engine uses Ed25519 node identities, X25519 key exchange, HKDF key derivation and ChaCha20-Poly1305 authenticated encryption.

Future Transports

The transport architecture is intended to expand toward Wi-Fi Direct, Bluetooth LE, LoRa, Meshtastic-compatible radios, Ethernet and native Apple networking.

iPhone Architecture

This page can run in Safari on iPhone. The current native MeshBridge executable is a macOS binary and does not execute directly inside Safari. A native iOS networking layer is required for direct iPhone mesh operation.
