🛡️ Local-First Storage Guarantee:

Emails, images, attachments, and database indexes exist solely on this computer's hard drive within IndexedDB. GitHub Pages only serves the static interface code and does not receive or store any user data.

How Multi-Device Access Works Without a Cloud:

Instead of saving your email password on a server, your account is bound to a cryptographic session key. When you enter this key on a second computer, that computer authorizes itself with the mail exchange and downloads the inbox to its own local hard drive.
